# PAS 1 — проект для сборки через GitHub Actions

В архиве уже сохранена правильная структура репозитория: `.github/workflows/pas1-build.yml` находится рядом с каталогом `pas1/`. Не переносите workflow внутрь `pas1/`, иначе GitHub Actions его не обнаружит.

## Как запустить сборку

1. Создайте на GitHub пустой репозиторий. Не добавляйте там README, `.gitignore` или лицензию — они уже входят в архив.
2. Распакуйте архив. Откройте терминал в папке `PAS1-GitHub` — в ней должны быть `.github/`, `pas1/` и `.gitignore`.
3. Установите Git, если он ещё не установлен, затем выполните команды, подставив адрес своего репозитория вместо `USER/REPO`: 

```sh
git init
git add .
git commit -m "Initial PAS 1 project"
git branch -M main
git remote add origin https://github.com/USER/REPO.git
git push -u origin main
```

4. Откройте репозиторий на GitHub → **Actions**. После отправки файлов workflow **PAS 1 build** запустится автоматически. Если GitHub попросит разрешить Actions, подтвердите это в репозитории.
5. Дождитесь завершения заданий для Windows, macOS и Linux. В завершённом запуске скачайте артефакт `PAS1-Windows`, `PAS1-macOS` или `PAS1-Linux`. Внутри будет VST3 и Standalone для соответствующей ОС.
6. Установите VST3 в папку плагинов своей системы и выполните повторное сканирование плагинов в DAW. Сборка macOS не подписана и может потребовать разрешения системы.

При первой сборке GitHub скачает JUCE 8.0.8. В архив не включены локальные CMake-сборки и кэши.
